Cake logical

Project type: Client work
Type: Offline client app-project, delivered to a paying custumer (a confectioner tracking ingredient costs)
Year: 2026
Language: RUS
Framework: Electron
Data storage: localStorage
Design: Warm pastry-inspired color palette
Core technologie: HTML, CSS, JavaScript

Cake logical is originally built for a real client, this is a calculator that estimates the ingredients needed for cakes and other desserts.
It helps work out exacly what to buy for each customer order.

How the app works

  1. It all starts on the main screen. At the top is the “Add product” block: name, unit of measurement, quantity, price type, and price. Below is the “Products” section, which already holds the first card: “eggs”, 3 pieces at 15 Kč, total 45.00 Kč. On the right of the card are edit and delete buttons.

  2. First, the user enters a name and chooses a unit of measurement. The list has five options: kilograms, grams, liters, milliliters, and pieces. This shows right away that the app handles weight, volume, and countable items.

  3. Next, the user specifies how the price is shown in the store. This is what the “Price type” field is for. The price can be entered per kilogram or liter, per package by grams, per package by pieces, or per piece. The price field sits to the right, and its label changes depending on the chosen type.

  4. When you don’t know how many grams are in a tablespoon of flour or a cup of milk, the “Useful dimensions” window helps. It is a reference of measures: spoons, cups, packages, chocolate and cocoa. It helps quickly convert everyday measures into grams.

  5. Finally, if a card is no longer needed, the user presses the delete button. The app doesn’t delete it immediately but asks for confirmation: “Are you sure you want to delete this card?” with “Yes, delete” and “Cancel” buttons. This way data isn’t lost by an accidental click.
